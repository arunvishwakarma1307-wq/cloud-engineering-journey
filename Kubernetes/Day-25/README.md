# Day 25 - Working with Helm Repositories

## Objective

Learn how Helm Repositories work, how to search charts, inspect chart metadata, view default values, and explore complete chart information before installation.

---

## Practical Implementation

### Screenshot 1 - List Helm Repositories

Displayed all configured Helm repositories available on the local system.

### Screenshot 2 - Search Repository

Searched the Bitnami Helm Repository to view all available charts.

### Screenshot 3 - Search MySQL Chart

Searched specifically for the MySQL Helm Chart within the Bitnami Repository.

### Screenshot 4 - View Chart Metadata

Displayed the metadata of the MySQL Helm Chart including chart version, application version, description, and dependencies.

### Screenshot 5 - View Default Values

Displayed the default configuration (`values.yaml`) of the MySQL Helm Chart.

### Screenshot 6 - View Complete Chart Information

Displayed the complete information of the MySQL Helm Chart including metadata, default values, README, and documentation.
