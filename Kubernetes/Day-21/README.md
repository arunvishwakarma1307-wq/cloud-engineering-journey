# Day 21 - Creating Your First Helm Chart

## Objective

Create a custom Helm Chart using Helm CLI and understand its default folder structure.

---

## Practical Implementation

### Screenshot 1 - Create Helm Chart

Created a new Helm Chart using the `helm create` command.

### Screenshot 2 - Helm Chart Folder Structure

Viewed the default folder structure generated by Helm.

### Screenshot 3 - Chart.yaml

Opened the `Chart.yaml` file and explored the chart metadata.

### Screenshot 4 - values.yaml

Viewed the default configuration values available inside the Helm Chart.

### Screenshot 5 - Templates Folder

Explored the default template files generated by Helm.

### Screenshot 6 - Install Custom Helm Chart

Installed the custom Helm Chart as a Helm Release.

### Screenshot 7 - Verify Helm Release

Verified that the Helm Release was successfully deployed using `helm list`.
