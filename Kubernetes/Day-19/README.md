# Day 19 - Helm Release Management

## Objective

Learn how to manage Helm Releases by viewing release information, upgrading releases, rolling back to previous revisions, and uninstalling applications.

---

## Overview

Helm tracks every application installation as a **Release**. Each time a release is upgraded, Helm creates a new **Revision**. If an upgrade causes issues, Helm allows the application to be rolled back to a previous working revision. Helm also provides commands to inspect releases, view generated Kubernetes manifests, and completely remove applications from the cluster.
