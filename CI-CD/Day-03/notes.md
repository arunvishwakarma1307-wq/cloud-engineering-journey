# Day 03 - GitHub Actions Artifacts

## What is an Artifact?

A GitHub Actions artifact is a file or group of files produced during a workflow run that can be stored and downloaded after the workflow finishes.

Artifacts are commonly used to preserve build outputs, test reports, logs, packaged applications, and other files generated during CI/CD.

---

## Why Artifacts Are Used

Artifacts are useful because workflow runners are temporary environments.

After a workflow finishes, files created inside the runner are not normally available for later use.

Artifacts allow important generated files to be stored with the workflow run so they can be downloaded or used later.

---

## Build Output

A build output is a file or folder generated during the build process.

Examples include:

- Compiled application files
- Test reports
- Deployment packages
- Configuration files
- Build information
- Logs

A build output can be uploaded as an artifact after it is generated.

---

## GitHub Actions Artifact Action

GitHub Actions provides an official action for uploading artifacts:

```yaml
uses: actions/upload-artifact@v4
```

This action uploads selected files or directories from the workflow runner and stores them with the workflow run.

---

## Artifact Name

Each uploaded artifact can have a name.

Example:

```yaml
with:
  name: build-artifact
```

The artifact name helps identify the stored files in the GitHub Actions workflow summary.

---

## Artifact Path

The `path` option specifies which file or directory should be uploaded.

Example:

```yaml
with:
  path: build-output/
```

This tells GitHub Actions to upload the contents of the `build-output` directory.

---

## Artifact Upload Process

The general process is:

```text
Workflow starts
      ↓
Build or task runs
      ↓
Files are generated
      ↓
Artifact upload action runs
      ↓
Files are stored by GitHub Actions
      ↓
Artifact can be downloaded
```

---

## Artifact Download

After a workflow run completes, uploaded artifacts can be downloaded from the workflow run's summary page.

The downloaded artifact normally contains the files and directories that were selected during the upload process.

---

## Artifact vs Repository File

An artifact and a repository file serve different purposes.

| Repository File | Artifact |
|---|---|
| Stored in Git repository | Stored with workflow run |
| Version controlled | Generated during workflow |
| Usually source/configuration | Usually build output |
| Available through Git | Available through workflow run |
| Changes through commits | Generated by CI/CD |

---

## Artifacts in CI/CD

Artifacts are important in CI/CD pipelines because one stage can generate files that are needed later.

Example:

```text
Build
  ↓
Generate application package
  ↓
Upload Artifact
  ↓
Download Artifact
  ↓
Testing / Deployment
```

This allows generated files to move between different stages of a CI/CD process.

---

## Artifact Retention

GitHub Actions artifacts are stored only for a defined retention period.

Retention settings can be configured according to repository or organization policies.

Artifacts should therefore be used for generated workflow outputs rather than permanent source-code storage.

---

## Important Concepts

### Artifact

A file or collection of files stored from a workflow run.

### Upload

The process of sending generated files from the workflow runner to GitHub Actions storage.

### Download

The process of retrieving a stored artifact from a workflow run.

### Build Output

Files generated as a result of a build or CI process.

### Artifact Path

The file or directory selected for upload.

---

## Key Takeaways

- Artifacts preserve files generated during GitHub Actions workflows.
- Artifacts are useful for build outputs and reports.
- `actions/upload-artifact@v4` is used to upload artifacts.
- The `name` option identifies the artifact.
- The `path` option identifies what should be uploaded.
- Artifacts can be downloaded from a completed workflow run.
- Artifacts are useful for passing generated files between CI/CD stages.
- Artifacts are different from files permanently stored in a Git repository.
