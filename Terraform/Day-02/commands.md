# Day 2 - Terraform Commands

## Navigate to Day-02

```powershell
cd "C:\Users\ArunVishwakarma\Desktop\cloud engineering journey\Terraform\Day-02"
```

---

## Initialize Terraform

```powershell
terraform init
```

Initializes the Terraform working directory and downloads required providers.

---

## Validate Configuration

```powershell
terraform validate
```

Checks whether the Terraform configuration is valid.

---

## Create Execution Plan

```powershell
terraform plan
```

Shows the changes Terraform plans to make without applying them.

---

## Apply Configuration

```powershell
terraform apply
```

Applies the Terraform configuration.

When prompted:

```text
yes
```

---

## Display Terraform Outputs

```powershell
terraform output
```

Displays all defined Terraform outputs.

---

## Display a Specific Output

```powershell
terraform output file_name
```

Displays the value of the `file_name` output.

---

## List Terraform State Resources

```powershell
terraform state list
```

Shows resources currently tracked by Terraform state.

---

## Check Generated File

```powershell
Get-Content .\terraform-day2.txt
```

Displays the content generated by Terraform.

---

## Override a Variable

```powershell
terraform apply -var='message=Terraform Day-2 Custom Message'
```

Overrides the default value of the `message` variable for the current execution.

---

## Check Generated File After Variable Override

```powershell
Get-Content .\terraform-day2.txt
```

Expected:

```text
Terraform Day-2 Custom Message
```

---

## Destroy Terraform Resources

```powershell
terraform destroy
```

Destroys resources managed by Terraform.

When prompted:

```text
yes
```

---

## Verify File Deletion

```powershell
Get-ChildItem .\terraform-day2.txt
```

After `terraform destroy`, the generated file should no longer exist.

---

## Day-02 Workflow

```text
terraform init
terraform validate
terraform plan
terraform apply
terraform output
terraform state list
terraform destroy
```
