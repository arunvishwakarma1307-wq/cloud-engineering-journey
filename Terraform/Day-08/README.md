# Day 08 - Terraform Conditional Expressions & Functions

## Practical Summary

In this practical, Terraform conditional expressions and built-in functions were practiced.

The practical included:

- Conditional expression using `? :`
- Using the `environment` variable
- Testing `dev` and `prod` environments
- `upper()` function
- `lower()` function
- `length()` function
- `join()` function
- Combining conditional expressions and functions with Local Values
- Verifying results using Terraform outputs
