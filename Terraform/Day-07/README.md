# Day 07 - Terraform Locals & Expressions

## Locals

Terraform Local Values (`locals`) are used to assign reusable values inside a Terraform configuration.

In this practical, Local Values were created in `locals.tf` and then used inside a `local_file` resource.

---

## Files Created

The following files were used in this practical:

```text
locals.tf
main.tf
outputs.tf
local-output.txt
.gitignore
```

Terraform also generated:

```text
.terraform/
.terraform.lock.hcl
terraform.tfstate
terraform.tfstate.backup
```

The Terraform state files and `.terraform/` directory were excluded from Git using `.gitignore`.

---

## Local Values

Three local values were created:

```hcl
locals {
  project_name = "terraform-day-07"
  environment  = "learning"
  file_message = "Hello from Terraform Locals"
}
```

These values were reused in the Terraform configuration.

---

## Using Locals in a Resource

The Local Values were used inside a `local_file` resource:

```hcl
resource "local_file" "example" {
  filename = "${path.module}/local-output.txt"

  content = "${local.project_name} - ${local.environment} - ${local.file_message}"
}
```

Terraform created the file:

```text
local-output.txt
```

---

## Local Values in Outputs

The Local Values were also exposed through Terraform outputs:

```hcl
output "project_name" {
  value = local.project_name
}

output "environment" {
  value = local.environment
}

output "file_content" {
  value = local.file_message
}
```

---

## Local Expressions

A derived Local Value was created by combining existing Local Values:

```hcl
project_info = "${local.project_name}-${local.environment}"
```

The resource was then updated to use the derived value:

```hcl
content = "${local.project_info} - ${local.file_message}"
```

The final generated file contained:

```text
terraform-day-07-learning - Hello from Terraform Locals
```
